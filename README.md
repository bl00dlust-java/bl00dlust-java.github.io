# Кибергигиена
Бесплатный интерактивный курс по цифровой безопасности на русском языке.

## Структура проекта
- `index.html` — главная страница
- `css/styles.css` — оформление и адаптивная вёрстка
- `js/app.js` — модули курса, тесты, тема и сохранение прогресса
- `pages/course.html` — страница курса
- `pages/module.html` — страница отдельного модуля (например, `module.html?id=phishing`)
- `pages/about.html` — информация о проекте
- `pages/privacy.html` — политика хранения данных
- `assets/favicon.svg` — иконка сайта
- `run-local.bat` — запуск локального сервера в Windows

## Запуск
Можно открыть сайт на GitHub Pages или запустить локально: дважды нажми `run-local.bat`, затем открой http://localhost:8000.

Прогресс сохраняется только в локальном хранилище браузера. Регистрация не нужна.
