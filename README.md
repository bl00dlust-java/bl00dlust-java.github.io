# Кибергигиена — бесплатный курс цифровой безопасности

Статический русскоязычный сайт без регистрации и серверной части. Подходит для GitHub Pages и обычного локального HTTP-сервера.

## Сборка TypeScript

Для изменения логики установите TypeScript и выполните `tsc -p tsconfig.json`. Сайт использует результат компиляции `js/app.js`; во время работы браузеру не нужен TypeScript или отдельный сервер приложения. Сборка не добавляет тяжёлый runtime.

## Запуск локально

Откройте терминал в папке проекта и выполните одну из команд:

```powershell
py -m http.server 8000
```

или, если установлен Node.js:

```powershell
npx serve .
```

Откройте `http://localhost:8000` в браузере.

## Публикация на GitHub Pages

1. Загрузите содержимое папки проекта в корень репозитория.
2. В настройках репозитория откройте **Pages**.
3. Выберите публикацию из ветки `main`, папка `/ (root)`.
4. Сохраните настройки и откройте выданный GitHub Pages адрес.

## Состав

- `index.html` — оболочка сайта, навигация и метаданные.
- `css/styles.css` — дизайн-система, адаптивная сетка, состояния и анимации.
- `src/app.ts` — исходный TypeScript: логика модулей, уроков, тестов, результатов, FAQ и сертификата.
- `js/app.js` — скомпилированный браузерный JavaScript, который загружается сайтом.
- `tsconfig.json` — настройки сборки TypeScript.
- `assets/favicon.svg` — значок сайта.

## Возможности курса

- 6 модулей, 3 урока и 5 вопросов в каждом модуле; к каждому уроку добавлен расширенный теоретический блок.
- Самостоятельный выбор модуля и последовательное прохождение уроков.
- Порог завершения теста — 75%; количество попыток не ограничено.
- Разбор ответов после каждой попытки; переход к следующему модулю после результата, повтор теста находится между переходом к программе и следующим модулем.
- Дополнительные материалы ведут на русскоязычные ресурсы: Госуслуги, Банк России, МВД России, Роскомнадзор, Роспотребнадзор и российские образовательные материалы по безопасности.
- Локальное сохранение темы, текущего урока, прогресса и истории тестов в `localStorage`.
- Раздел результатов и сертификат для печати или сохранения в PDF после завершения всех модулей.
- Светлая и тёмная темы; при первом открытии используется системная тема устройства, её можно переключить вручную.
- Адаптация для мобильных экранов и поддержка `prefers-reduced-motion`.

## Хранение данных

Регистрация и серверное хранение не используются. Прогресс остаётся в локальном хранилище браузера на текущем устройстве. Очистка данных сайта может удалить его. Не вводите в учебные примеры настоящие пароли или коды подтверждения.

## Шрифты

Сайт использует DM Serif Display, Inter и Roboto Mono через Google Fonts. Для работы без подключения к Google Fonts предусмотрены системные резервные шрифты.


## Дополнительные разделы платформы

- `js/hub.js` — безопасные учебные сценарии, локальный поиск по материалам, генератор паролей и чек-лист.
- `css/hub.css` — стили дополнительных разделов на основе существующих переменных дизайн-системы.
- `js/welcome-init.js` и `js/welcome.js` — экран возвращения к сохранённому обучению.

### Безопасность

Учебные тренажёры используют вымышленные примеры и не отправляют сообщения или данные на внешние ресурсы. Генератор паролей использует Web Crypto API в браузере. Чек-лист хранится локально. Не вводите настоящие пароли, коды подтверждения или платёжные данные.

GitHub Actions запускает проверку синтаксиса JavaScript/TypeScript и CodeQL для JavaScript/TypeScript. Frame Security Scan ориентирован на Python и не является подходящим анализатором для текущего стека проекта.


### Редактирование материалов и тренажёров

- `admin/index.html` — локальная панель управления.
- `admin/content.html` — редактор базы знаний, словаря и официальных ссылок.
- `admin/simulators.html` — конструктор учебных сценариев с вариантами ответов и объяснениями.
- `data/hub-content.json` — публикуемые статьи, термины и ссылки.
- `data/simulators.json` — вымышленные интерактивные учебные сценарии.

Админ-панель использует GitHub Contents API: владелец вводит fine-grained token вручную с правом Contents: Read and write для одного репозитория. Токен не записывается в файлы сайта и не сохраняется в localStorage. Это не серверная авторизация: не размещайте ссылку на админ-панель как секрет и не вводите токен на общедоступном устройстве.

Статистика посетителей не включена: GitHub Pages не предоставляет серверную базу аналитики. Для глобальной статистики нужен отдельный сервис аналитики или собственный сервер; локальные данные прогресса не являются статистикой всех посетителей.
